# Contributing to Beamstack projects

This is the **organisation default**. A project with its own `CONTRIBUTING.md`
overrides this file — read that one.

## Before you start

- Check the project's tier in the
  [Beamstack License Framework](https://github.com/TheBeamstack/beamstack-licensing).
  Only **Open** and **Community / Community-Network** tier projects take outside
  contributions; **Commercial** and **Dedicated** projects generally do not.
- Read the project's `LICENSE` (and `LICENSING.md` if present).

## The essentials

1. **Contributor License Agreement.** You need the
   [Beamstack CLA](https://github.com/TheBeamstack/beamstack-licensing/blob/main/templates/CLA.md)
   on file before your first contribution is merged. You keep your copyright; you
   grant Beamstack a re-licensing and patent licence. This keeps commercial
   dual-licensing possible across the ecosystem.
2. **Sign off every commit** (`git commit -s`) — the
   [DCO 1.1](https://developercertificate.org/).
3. **One topic per pull request.** Add or update tests. Match the surrounding
   code's style and conventions.
4. **Dependencies:** don't add a copyleft or source-available dependency without
   raising it first.
5. **Code of Conduct:** all participation is under
   [our Code of Conduct](CODE_OF_CONDUCT.md).
