# `.github` — Beamstack organisation defaults

This repository holds **organisation-wide GitHub community-health files** for the
`TheBeamstack` org. GitHub applies these to every repository in the org that does
not provide its own copy.

| File | Purpose |
|---|---|
| [`profile/README.md`](profile/README.md) | The org profile page shown at `github.com/TheBeamstack` |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Contributor Covenant 2.1 — applies to all repos |
| [`SECURITY.md`](SECURITY.md) | How to report a vulnerability |
| [`SUPPORT.md`](SUPPORT.md) | Where to get help |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Org default; individual projects override with a project-specific one |
| [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) | Default PR template |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/) | Default issue forms |

Licensing policy lives in a separate repo:
**[beamstack-licensing](https://github.com/TheBeamstack/beamstack-licensing)**.

To override any of these for a specific project, add a file of the same name to
that project's repo (or its own `.github/` folder).
